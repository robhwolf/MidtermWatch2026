# Midterm Watch dashboard

Scope: single-page dashboard, Operate mode. Friends in a group chat, on phones, election night.
Chosen route: the category standard, as the user steered it: news-site structure with flourishes too daring for a network. Reference bar: NYT and Washington Post results pages. Natural look and muted party colours from the original brief still bind.

## Direction contract

THESIS: A familiar results page whose seat bars are alive. Refuses both the KPI-card dashboard and the cream-and-serif "organic" default.
OWN-WORLD: Cool lichen-white ground, pine ink, muted slate blue and brick red, moss neutrals; Schibsted Grotesk text, Big Shoulders numerals; dark night theme. Meadow blades, pebble tiles, dusk rail, pencil ring.
STORY: See where each chamber stands, what just changed, what is left, then drill into states and races.
FIRST VIEWPORT: Masthead with update time; House meadow with giant D and R counts either side and the majority marker; Senate meadow; governors count; latest calls beneath on desktop.
FORM: Category standard (canon), user-steered; seed key 39fea4ab. Signature: one blade per seat, ripple on a real call.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
