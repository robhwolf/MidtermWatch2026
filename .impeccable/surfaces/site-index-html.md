# Midterm Watch dashboard

Scope: single-page dashboard, Operate mode. Friends in a group chat, on phones, election night.
Chosen route: The Topo Quad, Linen palette, chosen by the user over several previews. The user asked to remove background contour lines and the state map, and asked for brown and cream rather than green.

## Direction contract

THESIS: A results page set like a survey sheet, read off scale bars. Refuses the KPI-card dashboard and the green outdoorsy map costume.
OWN-WORLD: Linen ground, brown ink, muted slate blue and brick red; Walnut as dark theme; Archivo Narrow numerals and legend heads, Source Sans 3 text. Scale bars, benchmark marker, ruler rules, dashed trail, pencil ring.
STORY: See where each chamber stands and what was just called, then what is left, then drill into races.
FIRST VIEWPORT: Masthead with update time; Latest calls on phones once any exist; House and Senate counts over scale bars with the majority benchmark.
FORM: Topo Quad; position 3 on the grounded list; seed:4f78fc6e0f2dec71. Signature: seat scale bar, sweep on a real call.
